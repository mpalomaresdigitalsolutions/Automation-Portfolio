🧠 The Multi-Turn Strategy Engine

Unlike rigid web forms that drop drop-offs, the DeepSeek AI agent acts as a live qualification consultant:

  • Strict JSON Handshake: Enforces schema { "is_pass_next": boolean, "message": "..." } for programmatic branching.

System 03 · Retrieval-Augmented Generation (RAG)

Airbnb RAG Guest Concierge — FiFi

🟢 Production Vector Architecture

An autonomous hospitality AI assistant. Features an automated hourly Knowledge Base synchronizer connected to Google Drive and Supabase vector store, coupled with a guest-facing conversational agent equipped with safety guardrails.

1 · Vector Store Auto-Sync Pipeline

Maintains fresh property information without manual re-indexing:

  • Google Drive Poller: Monitors property documentation for updates every 60 minutes.
  • Text Chunker: Splits content into 500-character windows with 50-character semantic overlaps.
  • NVIDIA Nemotron 120B Embeddings: Converts chunks into dense high-dimensional vectors.
  • Supabase (pgvector): Inserts embeddings with cosine distance matching for instant lookup.

2 · RAG Guest AI Concierge

Answers guest questions with property-grounded precision:

  • Property-First Priority: Searches Supabase vector store before falling back to general search.
  • Amenity Direct Links: Provides hot tub, TV, WiFi, and appliance operation guides instantly.
  • Safety Guardrails: Politely declines unauthorized guest additions and routes emergencies to host/911.
  • Audit Trail: Logs guest question, AI answer, and timestamp to Google Sheets.
System 04 · Vertical Market Intelligence

Real Estate Market Trend Report — AI Market Intelligence

🟢 Enterprise Semantic Search

A vertical RAG assistant for real estate professionals. Ingests raw market reports into Weaviate using Cohere embeddings, allowing brokers and investors to query real-time trends, regional prices, and historical performance with zero hallucinations.

1 · Market Data Ingestion Pipeline

Processes market reports, listings, and pricing updates:

  • Custom Ingest Form: Secure endpoint for raw real estate bulletins and listings.
  • Recursive Splitter: 400-character chunking with 40-character overlap for optimal semantic density.
  • Cohere embed-english-v3.0: State-of-the-art embedding model for commercial search.
  • Weaviate Vector DB: Stores vectors in isolated collections for instant filtered querying.

2 · Grounded Q&A + Audit Logging

Ensures verified data delivery to clients and brokers:

  • Grounded Reasoning: If market data lacks relevant stats, the agent prompts for clarification rather than guessing.
  • Conversation Memory: Seamless multi-turn session tracking for complex financial queries.
  • Complete Compliance Log: Records full user queries, responses, and latency in Google Sheets.
